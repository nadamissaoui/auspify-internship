# Demo Videos

Vidéos de démonstration de chaque tâche (format WebM, enregistrées avec Playwright / Chromium).

| Fichier | Tâche | Durée | Contenu |
|---|---|---|---|
| `task1-portfolio.webm` | Task 1 – Portfolio | ~21s | Navigation entre les pages, scroll des sections, remplissage et envoi du formulaire de contact |
| `task2-student-management.webm` | Task 2 – Student Management | ~16s | Ajout d'un étudiant, recherche, tri par note, modification, suppression |
| `task3-expense-tracker.webm` | Task 3 – Expense Tracker | ~24s | Inscription, ajout de revenus/dépenses, mise à jour du tableau de bord et du graphique |
| `task4-ecommerce-checkout.webm` | Task 4 – E-Commerce | ~25s | Navigation catalogue, recherche, inscription, panier, modification de quantité, commande |
| `task4-ecommerce-admin.webm` | Task 4 – E-Commerce (Admin) | ~15s | Connexion admin, tableau de bord, changement de statut de commande, gestion des produits |

## Lecture

Les fichiers `.webm` peuvent être lus dans :
- Chrome / Edge / Firefox (glisser-déposer le fichier dans le navigateur)
- VLC
- En ligne de commande avec ffmpeg / ffplay

> Astuce : pour convertir en MP4 (compatible partout), avec une installation ffmpeg complète :
> `ffmpeg -i task1-portfolio.webm -c:v libx264 -crf 28 task1-portfolio.mp4`
